The name

A Sundanese word, and why the app is named after it.

Badami is a verb in Sundanese, the language spoken across western Java. It means to deliberate: to sit with something that matters and talk it through until there is agreement.

The name sets the rule the app follows. Badami gathers your projects, tasks, servers, and notes in one place, and leaves the deciding to you.

What is inside

Modules that normally live in separate apps, sharing one database and one keyboard shortcut.

Projects and pages

A block editor for project notes, specs, and nested pages, with everything searchable from one place.

Tasks

Priorities, labels, due dates, subtasks, recurring work, reminders, and both list and board views.

Daily planning

Drag tasks onto a calendar, write free-form notes per day, and watch the day fill up.

Today window

A small floating window with a Pomodoro timer, so the current task stays visible without the whole app.

Servers

SSH terminal with keepalive and reconnect, SFTP and FTP file manager, PEM key manager, saved commands, and a remote editor.

Local Dev macOS

Run *.test sites with your own nginx, PHP-FPM, MariaDB, and Redis. Badami owns the binaries, so nothing else has to be installed.

Credential vault

AES-256-GCM encrypted storage, a TOTP authenticator, and a password generator, unlocked by one master password.

REST API tool

Build and send requests, organize them into collections, keep per-environment variables, and import from Postman.

Database client

Connect to MySQL, PostgreSQL, and SQLite, browse tables, edit schema, run queries in tabs, and export results.

AI assistant

Chat with any OpenRouter model, with tool use and streaming, from inside the same window.

Stats and search

A productivity dashboard for the last 30 days, and a palette that finds anything in the app.

Sync

Optional replication to Turso, so the same work is on more than one computer.

Install

Prebuilt installers for macOS, Windows, and Linux are attached to every release. The in-app updater keeps them current from there.

Platform File to download
macOS, Apple Silicon badami_<version>_aarch64.dmg
Windows badami_<version>_x64-setup.exe or .msi
Linux .AppImage, .deb, or .rpm

Full walkthrough, including the first-launch step on macOS, is in Install.

Build it yourself

Badami is a Tauri v2 app: a Rust backend with a React and TypeScript frontend, storing everything in SQLite on your machine.

~/code/badami 
git clone https://github.com/khalidinsan/badami.git
cd badami
npm install
npm run tauri dev

The first build compiles the Rust crates and takes a few minutes. Setup per platform, the project layout, and how releases are cut are in Development.
