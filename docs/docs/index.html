Badami docs

Badami keeps the tools you already use for shipping software in one desktop app. Everything is stored locally in SQLite, and cloud sync is optional.

Install

Download a prebuilt installer for macOS, Windows, or Linux, clear the first-launch prompt on macOS, and let the in-app updater handle the rest.

Projects and pages

Organize work into projects, write in a block editor, and keep specs and notes next to the tasks they belong to.

Tasks

Smart lists, labels, subtasks, deadlines, repeating work, and reminders, in a list or on a board.

Planning and Today

Plan the day on a calendar, then work from a small floating window with a Pomodoro timer.

Servers

SSH terminal, file manager, saved commands, and a remote editor, with secrets kept in the system keychain.

Credential vault

One master password over an encrypted vault, with a TOTP authenticator and a password generator.

REST API tool

Build and send requests, organize them into collections, and keep per environment variables.

Database client

MySQL, PostgreSQL, and SQLite with a table browser, a schema editor, and query tabs.

AI assistant

Chat with any OpenRouter model, with streaming replies and tool use, from inside the same window.

Stats and search

A dashboard of the last 30 days, and a command palette that finds anything in the app.

Sync

Optional replication to Turso, so the same work is on more than one computer.

Local Dev macOS

Serve *.test sites from nginx, PHP-FPM, MariaDB, and Redis that Badami installs and manages itself.

Settings reference

Every option in the app, with its default value and what changing it does.

Keyboard shortcuts

Every key binding, grouped by where it works.

Where your data lives

Badami stores everything on your machine first. Two databases live side by side under your user account:

File Purpose
badami.db The local database. Always present.
badami_sync.db Embedded replica, created only when cloud sync is enabled.

Both sit in the app's support folder, which on macOS is ~/Library/Application Support/com.khalid.badami/.
