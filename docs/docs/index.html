Badami docs

Badami keeps the tools you already use for shipping software in one desktop app. Everything is stored locally in SQLite, and cloud sync is optional.

Install

Download a prebuilt installer for macOS, Windows, or Linux, clear the first-launch prompt on macOS, and let the in-app updater handle the rest.

Local Dev

Serve *.test sites from nginx, PHP-FPM, MariaDB, and Redis that Badami installs and manages itself.

Development

Toolchain requirements per platform, running from source, producing release bundles, and how a tagged release is published.

Architecture

Where things live in the repository, which library handles each concern, and how the version number stays in sync across three files.

The modules

Each module shares one database and one search. Nothing is a separate window you have to remember to open.

Module What it does
Projects and pages Block editor for notes, specs, and nested pages.
Tasks Priorities, labels, due dates, subtasks, recurring work, reminders, list and board views.
Daily planning Calendar you drag tasks onto, plus free-form notes per day.
Today window Floating compact window with a Pomodoro timer.
Servers SSH terminal, SFTP and FTP file manager, PEM keys, saved commands, remote editor.
Local Dev macOS Local PHP stack with Badami-owned nginx, PHP-FPM, MariaDB, Redis, and dnsmasq.
Credential vault AES-256-GCM vault, TOTP authenticator, password generator.
REST API tool Request builder, collections, environments, Postman import.
Database client MySQL, PostgreSQL, and SQLite with a query editor and table viewer.
AI assistant OpenRouter models with tool use and streaming responses.
Stats Productivity dashboard.
Sync Optional Turso LibSQL cloud sync with embedded replicas.

Where your data lives

Badami stores everything on your machine first. Two databases live side by side under your user account:

File Purpose
badami.db The local database. Always present.
badami_sync.db Embedded replica, created only when cloud sync is enabled.

Both sit in the app's support folder, which on macOS is ~/Library/Application Support/com.khalid.badami/.
