Stats and search

Two small features that are about everything else: a dashboard of how the last month went, and a palette that finds anything in the app from the keyboard.

Statistics

The Statistics page summarises the last 30 days. There is no range selector; the window is fixed.

Card What it counts
Total Sessions Completed Pomodoro sessions.
Total Focus Their combined minutes, shown as hours and minutes.
Avg Duration Average length of a completed session.
Day Streak Consecutive days ending today with at least one completed session. It reads zero until today has one, so a streak can look broken in the morning.

Two charts cover the same window:

Chart Series
Pomodoro Sessions (30 days) Sessions per day, and tasks completed per day.
Focus Minutes (30 days) Minutes of focus per day.
Only completed work counts

A Pomodoro session you cancel is excluded from every number, and a task counts only when its status is Done, so a cancelled task is not counted even if it has a completion time.

Search and commands

Cmd+K opens the palette over whatever you are doing. Cmd+Shift+K opens the same search in its own small window from anywhere on the system, which is useful when Badami is not in front.

What it searches

One query covers every module, with results grouped by type:

Type Items
ProjectsBy name.
TasksEvery task, including subtasks.
PagesProject pages by title.
ServersSaved connections.
CredentialsVault entries by name.
APICollections and saved requests.
DatabaseSaved connections.
CommandsActions rather than documents.

Scoping the query

Type a prefix to search only one kind of thing:

Prefix Scope
>Commands
#Tasks
@Servers
/Projects

There are also tabs across the top for the same filtering, and clicking one clears whatever you typed.

Commands

Beyond opening things, the palette can act. Alongside navigation entries there are commands to create a project or a task, and, on macOS, to open Local Dev, start or stop the local stack, and open the Doctor. Those Local Dev commands disappear when the module is turned off.

Recents

With an empty query, the palette lists what you used recently before anything else. That list is kept locally and holds the last ten items.

Limits

  • Results are capped at 25 rows, both for recents and for a typed query.
  • Matching is fuzzy on titles and subtitles only. It does not read the body of a page or a task's notes.
  • The index is built when the palette opens, so something you created while it was already open appears the next time you open it.
  • Selecting a task opens the Tasks view but does not select that task.
