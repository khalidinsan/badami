Tasks

One list that holds everything: a fast inbox, projects, labels, subtasks, deadlines, repeating work, and reminders.

The sidebar

The left column is how you slice the same list. Selecting anything there filters the view; All Tasks at the top clears every filter.

Entry What it selects
Inbox Tasks with no project.
Starred Tasks you marked with the star.
Today Due today.
Tomorrow Due tomorrow.
Next 7 Days Due within the coming week.
Overdue Past their due date and not finished.
Projects Collapsible list of active projects. Click one to filter to it.
Labels Collapsible list of labels, with their color. Click to filter.

Each smart list shows a count badge. The badge counts root tasks that are not finished, while the list itself has no status restriction, so a badge can read lower than the number of rows you see once you hide completed work.

Working with a task

Action How
Add a task Type in the input at the top and press Enter, or press n to jump to it.
Change status Click the checkbox. It cycles To Do, In Progress, Done, and back. A cancelled task also returns to To Do when clicked.
Add a subtask Hover a row and click +, or use the row menu. Enter adds, Escape cancels.
Open the detail panel Click the task. Escape closes it.
Reorder Drag a row, but only while the sort is set to Manual.
Move to another project Drag the task onto a project in the sidebar or onto a project group header.
Right-click a row Mark done or reopen, star, move to a project, add a subtask, or delete.

The detail panel

Clicking a task opens a panel on the right with everything about it: an editable title, a notes editor, and a properties section you can show or hide.

Property Values
Status To Do, In Progress, Done, Cancelled
Priority None, Low, Medium, High, Urgent
Project No project, or any project
Due date and time A date, plus an optional time
Estimate Free text that accepts 45m, 2h, or 1h 30m. A bare number is read as minutes.
Recurrence No repeat, every day, every week, weekdays, or every month
Labels Any number of labels
Reminders A list of date and time pairs; each can be removed

The bottom of the panel lists subtasks, and it is resizable by dragging its edge.

Subtasks

Subtasks nest inside their parent and can be collapsed. Nesting stops at three levels: once a task is two levels deep, the option to add another child is no longer offered.

Completing a task marks every task underneath it as done at the same time. Reopening a parent brings back only the parent; the children stay done.

Repeating tasks

Give a task a recurrence rule and a due date, and completing it creates the next occurrence on the following date the rule produces. The new task carries over the title, notes, priority, project, due time, estimate, and nesting, and it is linked back to the task it came from.

The presets cover daily, weekly, weekdays, and monthly. The rule is stored as a standard calendar string, so it survives a round trip through sync.

Reminders

Add one or more date and time pairs to a task. Badami checks for due reminders once a minute and raises an operating system notification, so it works whether or not the window is in front. A reminder is marked as sent once it fires, and the panel shows that next to it.

Reminders are separate from due dates. A task can be due on Friday and remind you on Thursday evening.

Filtering, sorting, grouping

Control Options
Search Matches task titles. It does not search notes.
Filters Status, priority, project, and label chips, plus a due date range. Clear all resets them.
Sort Manual, Due Date, Priority, Title, Date Created
Group by No grouping, or by project. Groups act as drop targets for dragging.
Hide done Toggles finished tasks in and out of the list.
View List or board.

Filters, sort, grouping, and view choice are not saved. They reset the next time the app starts.

Board view

The board has four fixed columns: To Do, In Progress, Done, and Cancelled. Drag a card into another column to change its status. A quick click selects the task instead of dragging it.

Labels

Manage labels opens a dialog where you can add a label with a name and color, and delete the ones you no longer use. Deleting a label removes it from every task that carried it; the tasks themselves stay.

Keyboard

These work while the Tasks view is the one on screen, and they are ignored while you are typing in a field.

Key Action
↓ / ↑Move the selection between tasks.
dCycle the selected task's status.
sStar or unstar the selected task.
DeleteDelete the selected task.
nFocus the add task input.
Any letterAlso focuses the add task input.
EscapeClose the detail panel.
EnterSubmit the add input or a label name.
Multi-select is not exposed

The code contains a bulk action bar with Complete, Move, Priority, and Delete for many tasks at once, but nothing in the interface can select more than one task, so the bar never appears. Treat bulk editing as unavailable.
