Projects and pages

A project gathers the work that belongs together: pages for notes, tasks, servers, credentials, API requests, and database connections, all behind one header.

The project list

/projects lists every project you have. The toolbar holds a New Project button, a Search projects... box that matches on project name, a status filter, and a category filter. Once any filter is active, a Clear button appears next to them.

Control Options
Status All, Active, On Hold, Completed, Archived. The default is Active.
Category Any category you have created.
Search Filters by project name as you type.

Clicking a card opens the project in its own tab inside the app window, so you can keep several projects open at once.

Project card actions

Right-click a project card for its menu.

Action What happens
Edit Opens the project dialog with the current values.
Archive Moves the project to Archived immediately. There is no confirmation step.
Delete Asks for confirmation first, warning that the project and all of its pages are removed permanently.

Empty states

When filters are active and nothing matches, the list shows No projects match your filters with a Clear filters link. With no filters set and no projects at all, it shows No projects yet with a Create your first project action.

Creating and editing a project

The project dialog holds the identity of the project.

Field Values
Name Required.
Description Optional free text.
Icon A picker with 12 icons.
Color A picker with 8 colors.
Category A select of existing categories, with inline creation. Type a new name and press Enter to add it, Escape to cancel. Each category in the list has its own delete control.

Inside a project

A project opens with All Projects to go back, a ... menu holding the same Edit, Archive, and Delete actions as the card menu, and a Search pages... box that filters the page sidebar.

Next to the Pages heading is a + button. It creates a page called Untitled Page with the category set to notes, and opens it.

The header tab strip

The top of a project switches between the module views that belong to it.

Tab Shows
ContentThe pages of the project.
TasksThe project's tasks, with a badge counting active tasks.
ServersSSH hosts attached to the project.
CredentialsVault entries attached to the project.
APIREST request collections attached to the project.
DatabaseDatabase connections attached to the project.
Local sitesLocal development sites. macOS only.

Tasks tab

The Tasks tab carries an inline input labelled Add a task... press Enter, plus view switching between list, board, and calendar. The calendar view opens a side panel listing the tasks due on the day you click.

Pages

The Overview entry at the top of the page sidebar renders the project's own rich text body. Pages you create sit underneath it.

Right-click a page in the sidebar for two actions:

Action What happens
Rename Opens a dialog; Enter submits the new name.
Delete Asks for confirmation first.

The page sidebar is resizable. Drag its edge to set the width; it stops at 224px on the narrow end and 480px on the wide end.

A page

A page is a title, a category, and a full-width block editor. The title is editable in place and saved 500ms after you stop typing. The category select offers Brief, Feature, Screenshot, Notes, and Custom. Deleting a page asks for confirmation.

Data and cascades

Projects, pages, and project categories live in three tables: projects, pages, and project_categories. Deleting a project removes its pages with it, and clears the project from its tasks. The tasks themselves survive.

Limits

Know what the interface does not remember

The project list opens on the Active status filter, so archived and on-hold projects stay hidden until you change the filter. The active header tab is not remembered between visits; you return to the first tab each time.

  • Page categories are free text in the database, but the interface only offers the five fixed values listed above.
  • Page title edits are debounced, so closing the page immediately after typing can lose the last edit.
