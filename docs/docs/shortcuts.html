Keyboard shortcuts

Shortcuts are scoped: a key does one thing in the Tasks list and something else in the Today window. On Windows and Linux, read Cmd as Ctrl.

Anywhere

Shortcut Action
Cmd+K Open or close the search palette inside the window.
Cmd+Shift+K Open search from anywhere, even when Badami is not the frontmost app. This is a system-wide shortcut.
Cmd+1 to Cmd+9 Switch to the tab in that position.
Cmd+W Close the active tab, unless it is pinned.

In the sidebar, a plain click navigates in the current tab. Holding Cmd while clicking, or middle-clicking, opens the destination in a new tab.

Search palette

Key Action
↑ / ↓Move the highlight.
EnterOpen the highlighted result.
EscapeClose the palette.

Type a prefix to narrow the search: > for commands, # for tasks, @ for servers, / for projects.

Tasks

These apply while the Tasks view is the one on screen, and they are ignored while you are typing.

Key Action
↓ / ↑Move the selection between tasks.
dCycle the selected task's status.
sStar or unstar the selected task.
DeleteDelete the selected task.
nFocus the add task input.
Any letterAlso focuses the add task input.
EscapeClose the task detail panel.
EnterSubmit the add input or a label name.

Today window

Active only in the floating Today window, and only when you are not typing.

Key Action
nOpen quick add.
↓ / ↑Move the selection.
SpaceToggle the selected task's status.
eExpand or collapse the selected task.
fFocus the task and start the Pomodoro timer.
pExpand the selected task. It does not open the priority menu.
Delete or BackspaceDelete the selected task and move the selection.
EscapeCollapse the expanded task, then clear the selection.

In quick add, @ starts a project mention: arrow keys move through the matches, Enter picks one, and Escape clears it.

Planning

Key Action
EnterIn the note field, create the note.
Enter or SpaceOn an unscheduled task, schedule it on the selected day.

Servers

Key Action
EnterIn terminal search, jump to the next match.
Shift+EnterIn terminal search, jump to the previous match.
EscapeClose terminal search.
EnterIn the file manager breadcrumb, navigate to the typed path.
EscapeCancel editing the breadcrumb.
Cmd+FFocus the file search box.

Editor and forms

Key Action
/Open the block menu in a rich text editor.
EnterSubmit a dialog or an inline field.
EscapeCancel a dialog, a rename, or an inline add.
One system-wide shortcut

Cmd+Shift+K is the only shortcut Badami registers with the operating system, so it is the only one that can conflict with another app. Everything else works while Badami is focused.
