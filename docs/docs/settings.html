Settings

Every option in the app, grouped the way the Settings page groups it, with the value it starts at and what changing it does.

Appearance

Setting Default Effect
Theme Dark Light, Dark, or follow the system. Applies immediately, everywhere.

Pomodoro Timer

These set the length of each phase. The value in force when you start a session is saved with that session, so changing the length later does not rewrite history.

Setting Default Range
Work duration 25 minutes 1 to 120
Break duration 5 minutes 1 to 60

Today Window

Setting Default Effect
Always on top by default On Intended to control whether the floating Today window stays above other windows. See the note below.
This toggle does not currently do anything

The Today window is created always on top regardless of this setting, and its own pin button changes only the live window without saving the change. Treat the window as always on top for now.

System

Setting Default Effect
Launch at login Off Registers Badami as a login item so it is running when you log in.
Close to system tray On Closing the window keeps Badami running in the background, so reminders and sync keep working. Turn it off to quit on close.
Show app in Dock On Whether Badami appears in the macOS Dock.

Updates

Shows the current version and checks GitHub Releases for a signed build. When one is available, download and install, then the app restarts. The update is verified against a signing key embedded in the app, so a build that does not match is refused.

Cross-Device Sync

Optional cloud replication through a Turso database. Off by default. See Sync for the full picture, including what is and is not replicated.

Setting Default Effect
Enable sync Off Turns replication on and creates the local replica on first run.
Database URL Empty The Turso endpoint to replicate against.
Sync interval 5 minutes How often the app pushes and pulls in the background.
Sync on launch On Runs a sync when the app starts.
Sync on close On Runs a sync when the app closes, so the last changes are not left behind.
Show sync status On Displays the sync indicator in the interface.

SSH Terminal

Applies to the terminal used in the Servers module.

Setting Default Effect
Font size 13 Terminal text size.
Font family JetBrains Mono Terminal typeface.
Theme Dark Terminal color scheme.
Auto reconnect On Reconnects by itself when the connection drops.
Max reconnect attempts 5 How many times it retries before giving up and telling you.
Keepalive interval 30 seconds How often a keepalive is sent. Shortening it helps on networks that drop idle connections.

File Manager

Setting Default Effect
Show hidden files Off Shows dotfiles when browsing a server.
Default local path ~/Downloads Where downloaded files land and where the local pane starts.

AI Assistant

Setting Default Effect
OpenRouter API key Empty Your key, stored locally. A test button verifies it against the provider.
Default model deepseek/deepseek-v4-flash Used for new conversations unless you switch model in the chat.
Active models Empty The subset of the model list you keep available, so the picker is not hundreds of entries long.

Credential Vault

Setting Default Effect
Auto-lock timeout 15 minutes Locks the vault after this much inactivity, so a walk away does not leave it open.
Password hint Empty A reminder shown on the unlock screen. Stored in plain text, so do not put the password itself there.

PEM Keys

Manage the private keys used for SSH authentication: import a key, give it a name, and optionally store a passphrase. Imported keys are encrypted at rest. A saved key can then be chosen as the authentication method on a server.

Local Dev

Settings, Doctor, and the runtime controls for the local PHP stack live in the Local Dev tab. They are covered in full on the Local Dev page:

Setting Default Effect
HTTP port 8080 The port nginx binds. Saving a new value regenerates config and restarts nginx.
Default PHP version 8.4 Used by sites that are not pinned to a version of their own.
TLD test The domain suffix for every local site.
Loopback address 127.0.0.1 The address sites and DNS resolve to.
Enable Local Dev On Hides the module from the sidebar and the command palette when turned off. macOS only.

Where settings are stored

Everything on this page is a row in the settings table inside your local database, except the values that belong to the operating system: login item registration, and server passwords and PEM passphrases, which live in the keychain. Settings that describe this machine, such as the Local Dev paths and ports, are excluded from cloud sync so a second computer does not inherit paths that do not exist on it.
