AI assistant

A chat panel that talks to any model OpenRouter offers, with streaming replies and tool use, so it can reach the rest of the app rather than only answering questions.

Setting it up

  1. Create an API key at openrouter.ai. OpenRouter is a gateway, so one key reaches models from many providers.
  2. Open Settings → AI Assistant and paste the key. There is a test button that verifies it against the provider before you rely on it.
  3. Choose a default model. The list is fetched live from OpenRouter, and you can keep a shortlist of the ones you actually use so the picker stays workable.

The key is stored in your local database and is never synced, so it does not travel to another machine through the sync feature.

Chatting

Capability Detail
Streaming replies Text appears as it is generated instead of after the whole answer.
Model switching Change model for a conversation without changing the default.
Tool use The model can call into the app to look things up and act, then continue the answer with what it found.
Conversation history Chats are stored locally so you can come back to them.

Where it appears

The assistant is a module of its own in the sidebar, and it is also available from inside a project so a conversation about that work stays next to it.

Cost and privacy are between you and the provider

Requests go from your machine to OpenRouter and on to whichever provider serves the model you picked. Badami does not proxy them. Usage is billed by OpenRouter on your key, and the provider's data policy applies to whatever you send, so treat the chat as leaving your machine.

No offline mode

Every reply needs a working connection to OpenRouter. Without one, the chat cannot answer, and the rest of the app is unaffected.
