Servers

Keep your machines in one list, open a terminal or a file manager on any of them, and let the passwords live in the operating system keychain.

The server list

The Servers page shows a count of your servers and an Add Server button. Each server is a card. Clicking a card opens it in its own app tab.

Control What it does
Search Free-text filter over name, host, and username.
Filter A popover with Environment, Protocol (All, SSH, FTP, FTPS), and Project selects.
Clear filters Appears once any filter is active.
Sort Last connected (default), Name, Created, Updated.
Group No grouping, By project (default), By protocol.

Card actions

Action Notes
Terminal SSH only. On FTP or FTPS it shows a toast instead.
Editor SSH only. On FTP or FTPS it shows a toast instead.
Files Always available.
Right-click Edit and Delete.

Delete asks for confirmation. It also removes the stored password and passphrase from the operating system keychain.

Adding a server

Field Values
Name Free text.
Project Shown only on the global Servers page.
Environment Production, Staging, Development, Other.
Color Nine swatches.
Protocol SSH, FTP, FTPS.
Host, Port, Username Connection target.
Authentication Password, PEM Key File, Saved PEM Key, PEM Key + Passphrase, or From Credential Manager. The PEM options appear only for SSH.
Initial Directory Where the file manager and terminal start.

Changing the protocol resets the port to that protocol's default and forces password authentication for non-SSH protocols. Defaults: SSH 22, FTP 21, FTPS 21.

Secrets stay out of the database

Passwords and passphrases are written to the operating system keychain, never to the Badami database. Only the reference is stored alongside the server.

How authentication is resolved

When a session connects, the credential is resolved in one of these ways:

  • A password read from the keychain.
  • A PEM file path used directly.
  • A saved PEM key decrypted from storage.
  • A PEM file plus a passphrase read from the keychain.
  • A linked credential whose password field is decrypted from the vault.

Sessions

Sessions open in a full-page view with one tab per session, and each tab shows a status dot. The + menu lists every server with SSH, Files, and IDE buttons. Closing the last tab returns you to the list.

SSH terminal

The terminal connects on its own. It shows the connection state, user@host:port, and a live elapsed timer. The toolbar has Open File Manager, Saved Commands, a search toggle, and Reconnect when the connection drops.

Terminal search: Enter jumps to the next match, Shift+Enter to the previous one, and Escape closes the search bar.

Opening a terminal from a breadcrumb

When you start a terminal from a file manager breadcrumb, it runs cd <path> about 300 ms after connecting, so the shell lands in the directory you were browsing.

Saved commands

The Saved Commands panel has a search box, an add form, and edit and delete on each entry. A Run versus Insert toggle decides what happens when you pick a command: Run is the default and appends a newline, Insert only types the text. A Global checkbox makes a command server-independent so it shows up everywhere.

File manager

The file manager also connects on its own. Its toolbar has:

  • Up, home, and refresh.
  • An editable breadcrumb: click the path to type, Enter navigates, Escape cancels.
  • Open in Terminal.
  • A "Search files" box.
  • Transfer history.
  • A hidden-files toggle.
  • New folder and Upload file.

You can also drop files onto the window. A confirmation dialog lists the dropped files before the upload starts.

Per-file actions

Action Notes
Preview Text files up to 1 MB.
Download Saves a copy locally.
Edit Text files up to 5 MB.
Open in Code Editor Downloads the file to a temp folder, opens it in your editor, then watches it and uploads changes automatically after a short delay.
Rename Renames in place.
Delete Removes the remote file.
Protocol limits

Terminal and Editor are SSH-only features. On an FTP or FTPS server they only show a toast, so plan on using Files for those protocols.
