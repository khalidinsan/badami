Install

Prebuilt installers are attached to every release. Pick the file for your platform, then let the in-app updater keep it current.

1. Download

Open the latest release and download the asset for your platform.

Platform Asset Notes
macOS, Apple Silicon badami_<version>_aarch64.dmg Apple Silicon only for now. Intel builds are not published.
Windows badami_<version>_x64-setup.exe The .msi is available if you prefer it.
Linux .AppImage, .deb, or .rpm Choose whichever fits your distribution.

2. Install

macOS

Open the DMG and drag Badami to Applications. Builds are signed so the in-app updater can verify them, but they are not notarized by Apple yet, which means Gatekeeper may refuse the first launch. Clear the quarantine flag once: 

# After dragging Badami to Applications
xattr -cr /Applications/badami.app
open /Applications/badami.app
Why this is needed

The signature that matters for updates is the minisign key embedded in the app. Notarization is a separate, paid Apple step and is not set up yet. Removing the quarantine attribute does not disable Gatekeeper for anything else on your machine.

Windows

Run the setup executable and follow the installer. SmartScreen may warn about an unrecognized publisher for the same reason: the build is not signed with a Windows code-signing certificate.

Linux

AppImage: make it executable and run it. 

chmod +x badami_<version>_amd64.AppImage
./badami_<version>_amd64.AppImage

For .deb and .rpm, install with your package manager as usual.

3. Updates

Badami checks for a newer release on startup. You can also check by hand from About → Updates or Settings → Updates.

The updater reads this endpoint:

https://github.com/khalidinsan/badami/releases/latest/download/latest.json

Every artifact is minisign-signed, and the public key is embedded in the app at src-tauri/tauri.conf.json. An update that does not verify against that key is refused.

Uninstalling

Remove the app the way you normally would for your platform. If you also want to delete your data, remove the app support folder (~/Library/Application Support/com.khalid.badami/ on macOS). If you had enabled Local Dev, see Local Dev → Uninstall for the privileged pieces it can install.
