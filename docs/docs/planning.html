Planning and Today

Two views of the same due dates. The Planning page is where you place work on days. The Today window is a small floating list of what is left.

Daily Planning

/planning opens on a Calendar view with a Calendar / Agenda toggle above it. The calendar has previous, next, and today controls, a title, and a month / week switcher. Month is the default.

Clicking a day opens the daily plan panel for that date. Dragging an event onto another day reschedules it: the drop rewrites the due date of the underlying task. Completed events render greyed out with a line through them.

Agenda view

The agenda lists the next 30 days grouped by date. Each day header opens the daily plan panel for that date, and each task in the list carries the same three-state checkbox used elsewhere.

The daily plan panel

The panel slides in at a fixed 320px width. Its header holds the date, an Import from project dropdown, and a close button. Below that is a summary reading N/M completed with a progress bar, then the list of rows, each with a drag handle.

  1. Click a day in the calendar, or a day header in the agenda, to open the panel.
  2. Add a plan with the Add a note... input; Enter creates it for the selected date.
  3. Schedule unscheduled work by clicking a task in the pool, or dragging it into the list.
  4. Reorder or move rows with their drag handles, and right-click a row for its menu.
Action How
Mark done or reopen From the row context menu.
Remove from today From the row context menu. This clears the task's due date.
Reschedule Drag the event to another day in the calendar.
Import a project Pick the project from the Import from project dropdown.

What "Import from project" does

Choosing a project sets the due date to the selected day on every unfinished root task of that project whose due date is empty or different. It moves those tasks; it does not copy them. Subtasks and finished work are skipped.

The Unscheduled pool

The pool lists unfinished root tasks that have no due date. Click one to schedule it on the selected day, or press Enter or Space on the highlighted row. Tasks can also be dragged from the pool into the daily list.

An empty list reads No plans for this day and accepts a drop with the hint Drop to add.

The Today window

The Today button in the sidebar opens a separate small window, 300x480 by default and 260x360 at minimum. It has no title bar, it stays above other windows, and it remembers its position and size between launches.

The header shows Today with a completed over total counter and a progress strip. While a task is focused, a Focusing badge appears next to it.

Window controls

Control What it does
Font size Steps through three sizes. The whole window scales with it, because the sizes are relative.
Change color Six palettes: Default, Yellow, Green, Pink, Purple, Slate.
Filter by project All Tasks, Inbox, and each project that has tasks, with counts.

Refresh Reloads the list.
Close Closes the window.

The list

The list splits into an Overdue section and a Today section. Hovering a row reveals its actions: set priority (Urgent, High, Medium, Low, or None), assign a project, Focus, and Delete.

Clicking a row title expands it. The expanded row contains a notes editor, subtasks (Enter adds one, Escape cancels), a due date picker, a due time input, and an Open in Tasks button.

Add note reveals a quick-add input that supports an @ mention. Typing @ lists up to five matching projects; the arrow keys move the highlight, Enter selects, and Escape clears the mention.

Pomodoro

A Pomodoro toggle sits in the footer. While the timer runs, a compact mm:ss chip shows in the window. The timer itself offers Reset, Play/Pause, and Skip, a progress ring, a label that reads Ready, Focus, Break, or Paused, an N sessions today count, and a back button.

Focusing a task starts the pomodoro automatically when it is idle. When the session ends, a bar appears with Mark Done and Keep Going.

Limits

The Today window ignores some of its own settings

The window is always created on top regardless of the Settings toggle, so that setting currently has no effect. The pin button changes the live window, but the choice is not remembered. Open in Tasks shows and focuses the main window, but it does not select the task there.

A "note" is a task

There is no separate notes table. A plan you add in the daily panel is stored as a task whose title is the note text, so it also appears in Tasks and in the Today window.

  • Reordering inside the daily list is not saved. The order you set is lost on reload.
  • The calendar has no event resize and no drag range selection.
  • The daily plan panel is a fixed width with no resize control.
  • The agenda fetches once when it mounts, so it does not pick up changes made elsewhere while it is open.
  • Overdue tasks do not appear in the daily plan panel.
  • The window loads all of today's and overdue tasks with no pagination.
  • The pomodoro timer in the Today window is independent of the one in the main window. Running both means two separate timers.
  • Note edits in the window are debounced 600ms, so closing it immediately after typing can lose the last edit.
  • The priority popover cannot be opened from the keyboard.
