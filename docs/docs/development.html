Development

Badami is a Tauri v2 app: a Rust backend, a React and TypeScript frontend, and SQLite for storage.

Requirements

Tool Version
Node.js 20 LTS or newer
Rust stable, 1.77 or newer
Tauri CLI v2, installed through the project's npm scripts

Install Rust

macOS and Linux:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
rustup update stable

On Windows, run rustup-init.exe and also install the Microsoft C++ Build Tools with the Desktop development with C++ workload.

Platform packages

macOS:

xcode-select --install

Ubuntu or Debian:

sudo apt update
sudo apt install -y \
  libwebkit2gtk-4.1-dev libssl-dev \
  libayatana-appindicator3-dev librsvg2-dev \
  patchelf pkg-config

Run from source

git clone https://github.com/khalidinsan/badami.git
cd badami
npm install
npm run tauri dev

The first run compiles the Rust crates and takes a few minutes. Later runs are incremental. The frontend also has a browser-only dev server at npm run dev, which is useful for layout work but has no Tauri commands available.

Tests

# Rust
cd src-tauri && cargo test --lib

# Frontend
npm test

# Types
npx tsc --noEmit

A few Rust tests read real machine state, such as whether a MariaDB server currently holds a datadir, and a few need a live install to copy from. Those are marked #[ignore] and run on demand: 

cd src-tauri && cargo test --lib -- --ignored

Build release bundles

# Only needed to produce signed updater artifacts
# export TAURI_SIGNING_PRIVATE_KEY="$(cat ~/.tauri/badami.key)"
# export TAURI_SIGNING_PRIVATE_KEY_PASSWORD=""

npm run tauri build

Bundles land in src-tauri/target/release/bundle/:

Platform Artifacts
macOS .dmg, .app, plus .app.tar.gz when updater artifacts are on
Windows NSIS .exe and .msi
Linux .deb, .AppImage, .rpm

Publishing a release

Version numbers live in three files and must stay in sync. A new feature phase bumps the minor version, a fix bumps the patch version.

File Field
package.json "version"
src-tauri/tauri.conf.json "version"
src-tauri/Cargo.toml version

The About page reads the version through Tauri, so it never needs editing by hand. Pushing a tag runs the release workflow, which builds on macOS, Ubuntu, and Windows, publishes a GitHub Release, and uploads latest.json for the in-app updater: 

git tag v1.16.0
git push origin v1.16.0

The workflow needs a TAURI_SIGNING_PRIVATE_KEY secret, and optionally TAURI_SIGNING_PRIVATE_KEY_PASSWORD. Without the key, updater artifacts cannot be produced.

Conventions

  • TypeScript runs in strict mode; the build fails on type errors.
  • Database access goes through Kysely, not raw SQL, outside migrations.
  • State lives in Zustand stores, one per domain.
  • IDs are UUID v4 and timestamps are ISO strings.
  • Icons come from Lucide React, never emoji.
