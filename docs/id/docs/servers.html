Server

Simpan semua mesin Anda dalam satu daftar, buka terminal atau file manager di salah satunya, dan biarkan password tersimpan di keychain sistem operasi.

Daftar server

Halaman Servers menampilkan jumlah server Anda dan tombol Tambah Server . Setiap server berupa kartu. Mengklik kartu akan membukanya di tab aplikasi tersendiri.

Kontrol Fungsinya
Cari Filter teks bebas untuk nama, host, dan username.
Filter Popover dengan Environment, Protocol (Semua, SSH, FTP, FTPS), dan pilihan Project.
Bersihkan filter Muncul saat ada filter yang aktif.
Urutkan Terakhir terhubung (default), Nama, Dibuat, Diperbarui.
Kelompokkan Tanpa pengelompokan, Berdasarkan proyek (default), Berdasarkan protokol.

Aksi pada kartu

Aksi Catatan
Terminal Hanya SSH. Pada FTP atau FTPS, yang muncul hanya toast.
Editor Hanya SSH. Pada FTP atau FTPS, yang muncul hanya toast.
Berkas Selalu tersedia.
Klik kanan Edit dan Hapus.

Penghapusan meminta konfirmasi. Tindakan ini juga menghapus password dan passphrase yang tersimpan dari keychain sistem operasi.

Menambahkan server

Kolom Nilai
Nama Teks bebas.
Proyek Hanya ditampilkan di halaman Servers global.
Environment Production, Staging, Development, Other.
Warna Sembilan pilihan warna.
Protocol SSH, FTP, FTPS.
Host, Port, Username Target koneksi.
Autentikasi Password, PEM Key File, Saved PEM Key, PEM Key + Passphrase, atau From Credential Manager. Opsi PEM hanya muncul untuk SSH.
Direktori Awal Direktori awal file manager dan terminal.

Mengubah protokol akan mengatur ulang port ke default protokol tersebut dan memaksa autentikasi password untuk protokol selain SSH. Default: SSH 22, FTP 21, FTPS 21.

Rahasia tidak disimpan di database

Password dan passphrase disimpan ke keychain sistem operasi, tidak pernah ke database Badami. Yang disimpan bersama server hanyalah referensinya.

Cara autentikasi diselesaikan

Saat sesi terhubung, kredensial diselesaikan dengan salah satu cara berikut:

  • Password yang dibaca dari keychain.
  • Path file PEM yang dipakai langsung.
  • PEM key tersimpan yang didekripsi dari penyimpanan.
  • File PEM ditambah passphrase yang dibaca dari keychain.
  • Kredensial tertaut yang field password-nya didekripsi dari brankas.

Sesi

Sesi terbuka dalam tampilan satu halaman penuh dengan satu tab per sesi, dan setiap tab menampilkan titik status. Menu + mendaftarkan semua server dengan tombol SSH, Berkas, dan IDE tombol. Menutup tab terakhir akan mengembalikan Anda ke daftar.

Terminal SSH

Terminal terhubung sendiri. Terminal menampilkan status koneksi, user@host:port, dan penghitung waktu berjalan. Toolbar memiliki Buka File Manager, Perintah Tersimpan, tombol pencarian, dan Sambung Ulang saat koneksi terputus.

Pencarian terminal: Enter melompat ke kecocokan berikutnya, Shift+Enter ke kecocokan sebelumnya, dan Escape menutup bilah pencarian.

Membuka terminal dari breadcrumb

Saat Anda memulai terminal dari breadcrumb file manager, terminal menjalankan cd <path> sekitar 300 ms setelah terhubung, sehingga shell berada di direktori yang sedang Anda jelajahi.

Perintah tersimpan

Panel Saved Commands memiliki kotak pencarian, formulir tambah, serta aksi edit dan hapus pada setiap entri. Toggle Jalankan vs Sisipkan menentukan apa yang terjadi saat Anda memilih perintah: Jalankan adalah default dan menambahkan baris baru, Sisipkan hanya mengetikkan teksnya. Checkbox Global membuat perintah tidak terikat server sehingga muncul di mana saja.

File manager

File manager juga terhubung sendiri. Toolbar-nya memiliki:

  • Tombol naik, home, dan refresh.
  • Breadcrumb yang bisa diedit: klik path untuk mengetik, Enter menavigasi, Escape membatalkan.
  • Buka di Terminal.
  • Kotak "Search files".
  • Riwayat transfer.
  • Toggle untuk file tersembunyi.
  • Folder baru dan Unggah file.

Anda juga bisa menjatuhkan file ke jendela. Dialog konfirmasi menampilkan daftar file yang dijatuhkan sebelum unggahan dimulai.

Aksi per file

Aksi Catatan
Pratinjau File teks hingga 1 MB.
Unduh Menyimpan salinan secara lokal.
Edit File teks hingga 5 MB.
Buka di Code Editor Mengunduh file ke folder sementara, membukanya di editor Anda, lalu memantau dan mengunggah perubahan secara otomatis setelah jeda singkat.
Ganti nama Mengganti nama di tempat.
Hapus Menghapus file di server.
Batasan protokol

Terminal dan Editor hanya tersedia untuk SSH. Pada server FTP atau FTPS keduanya hanya menampilkan toast, jadi gunakan Berkas untuk protokol tersebut.
