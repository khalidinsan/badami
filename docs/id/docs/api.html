Alat REST API

Susun request, atur di dalam collection, ganti environment, dan baca responsnya tanpa meninggalkan Badami.

Menyusun request

Tampilan request memiliki pemilih method dan field URL, lalu tab untuk bagian request lainnya:

Tab Isinya
Params Parameter query.
Headers Header request.
Body Body request.

Collection dan folder

Request tersimpan di dalam collection, dan sebuah collection dapat memuat folder. Setiap collection punya variabelnya sendiri, sehingga nilai milik satu kumpulan endpoint tidak bocor ke kumpulan lain.

Environment

Environment adalah kumpulan variabel bernama. Anda menyimpan satu untuk setiap target (local, staging, production) dan berpindah di antaranya dengan pemilih environment di tampilan request. Request diselesaikan terhadap variabel di environment yang aktif.

Autentikasi

Badami punya helper bawaan untuk skema yang umum:

  • Token Bearer.
  • Basic username dan password.
  • API key.

Anda juga dapat menautkan kredensial dari brankas, sehingga token tidak pernah diketik ke dalam request. Kredensial dibaca saat pengiriman dan rahasianya tetap di brankas.

Mengirim dan membaca respons

Request dijalankan melalui backend Rust, bukan browser, sehingga tidak terkena aturan CORS browser. Penampil respons menampilkan status, header, dan body, lengkap dengan tampilan kode untuk body saat Anda ingin bentuk mentahnya.

Riwayat

Panel riwayat menyimpan request yang pernah Anda kirim, sehingga Anda dapat kembali ke salah satunya lalu mengirim ulang atau mengeditnya tanpa menyusunnya dari awal.

Impor dan ekspor

Arah Format
Impor Collection Postman.
Ekspor cURL.

Cakupan per proyek

Request dapat dibatasi pada sebuah proyek. Proyek punya panel API-nya sendiri, sehingga endpoint untuk satu pekerjaan berada bersama bagian proyek lainnya, bukan menumpuk di satu tempat global.
