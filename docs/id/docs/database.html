Klien database

Terhubung ke MySQL, PostgreSQL, dan SQLite dari dalam aplikasi, jelajahi isinya, ubah schema, dan jalankan query di tab.

Koneksi

Sidebar menampilkan daftar koneksi tersimpan Anda. Setiap koneksi memuat engine, host, port, database, username, dan cara autentikasinya.

Engine Catatan
MySQL dan MariaDB Terhubung melalui TCP. Bisa dipakai untuk server lokal maupun host remote.
PostgreSQL Terhubung melalui TCP, dengan schema opsional untuk dibuka lebih dulu.
SQLite Membuka file di disk. Tanpa server, tanpa kredensial.

SSL dan tunnel SSH

Sebuah koneksi dapat mewajibkan TLS, dan dapat dialihkan melalui server SSH ketika database hanya bisa dijangkau dari dalam jaringan. Sisi SSH memakai ulang kredensial dan PEM key yang sama seperti modul Servers, sehingga host yang sudah Anda tambahkan di sana bisa dipilih tanpa mengetikkannya lagi.

Password

Password database disimpan ke keychain sistem operasi, bukan ke database aplikasi. Baris koneksi mencatat semuanya kecuali rahasianya.

Mendaftarkan stack lokal

Jika Anda memakai Local Dev, MariaDB yang dikelolanya dapat didaftarkan sebagai koneksi dengan sekali klik dari panel Local Dev, sehingga database lokal muncul di sini tanpa mengetik host dan port secara manual.

Menjelajahi objek

Setelah terhubung, penjelajah objek menampilkan daftar schema, tabel, view, dan kolom. Memilih sebuah tabel akan menampilkan strukturnya dan memungkinkan Anda menelusuri barisnya per halaman.

Yang bisa Anda lakukan Di mana
Memeriksa kolom, tipe, key, dan default Tampilan struktur tabel.
Membaca baris dengan paging Tampilan data tabel.
Memfilter dan mengurutkan tanpa menulis SQL Header kolom dan baris filter.
Mengedit sel langsung di tempat Klik ganda sebuah sel di tampilan data.
Menyisipkan atau menghapus baris Kontrol baris di tampilan data.

Editor query

Setiap query terbuka di tabnya sendiri, sehingga Anda dapat menyimpan beberapa pernyataan berdampingan dan berpindah di antaranya. Hasil muncul di bawah editor, dan hasil eksekusi terakhir tetap ada sampai Anda menjalankan yang lain.

Aksi Caranya
Menjalankan pernyataan Tombol jalankan, atau pintasan papan tik yang biasa di platform Anda.
Tab query baru Cmd+T.
Menutup tab Cmd+W.
Melihat apa yang pernah Anda jalankan Panel riwayat query.

Perubahan schema

Tabel dan kolom dapat dibuat, diubah, dan dihapus dari antarmuka. Pernyataan yang akan dijalankan aplikasi ditampilkan sebelum dieksekusi, sehingga perubahan tidak pernah diterapkan tanpa sepengetahuan Anda.

Ekspor dan impor

Hasil query dan seluruh tabel dapat dituliskan ke file, dan data dapat dibaca kembali. Formatnya dipilih saat Anda memulai ekspor.

Cakupan per proyek

Sebuah koneksi dapat dilekatkan ke proyek, yang menambahkan tab Database di dalam proyek tersebut sehingga database yang relevan hanya berjarak satu klik saat Anda mengerjakannya.

Pernyataan destruktif tidak dijalankan di sandbox

Editor mengirim apa yang Anda tulis. DROP atau DELETE tanpa WHERE langsung dijalankan, terhadap koneksi apa pun yang sedang dipilih. Periksa nama koneksi sebelum menjalankan apa pun yang menghancurkan data.
