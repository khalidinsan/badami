Instalasi

Penginstal siap pakai dilampirkan pada setiap rilis. Pilih berkas untuk platform Anda, lalu biarkan updater dalam aplikasi menjaganya tetap mutakhir.

1. Unduh

Buka rilis terbaru lalu unduh aset untuk platform Anda.

Platform Aset Catatan
macOS, Apple Silicon badami_<version>_aarch64.dmg Untuk saat ini hanya Apple Silicon. Build Intel belum diterbitkan.
Windows badami_<version>_x64-setup.exe Berkas .msi tersedia jika Anda lebih menyukainya.
Linux .AppImage, .deb, or .rpm Pilih mana pun yang cocok dengan distribusi Anda.

2. Instalasi

macOS

Buka DMG lalu seret Badami ke Applications. Build-nya ditandatangani agar updater dalam aplikasi dapat memverifikasinya, tetapi belum dinotarisasi oleh Apple, sehingga Gatekeeper bisa menolak pembukaan pertama. Bersihkan penanda karantina sekali: 

# After dragging Badami to Applications
xattr -cr /Applications/badami.app
open /Applications/badami.app
Mengapa ini diperlukan

Tanda tangan yang penting untuk pembaruan adalah kunci minisign yang tertanam di dalam aplikasi. Notarisasi adalah langkah Apple terpisah yang berbayar dan belum disiapkan. Menghapus atribut karantina tidak menonaktifkan Gatekeeper untuk hal lain di mesin Anda.

Windows

Jalankan berkas setup lalu ikuti proses instalasinya. SmartScreen mungkin memperingatkan penerbit yang tidak dikenal karena alasan yang sama: build-nya tidak ditandatangani dengan sertifikat code-signing Windows.

Linux

AppImage: buat dapat dieksekusi lalu jalankan. 

chmod +x badami_<version>_amd64.AppImage
./badami_<version>_amd64.AppImage

Untuk .deb dan .rpm, instal dengan manajer paket Anda seperti biasa.

3. Pembaruan

Badami memeriksa rilis yang lebih baru saat dijalankan. Anda juga dapat memeriksanya secara manual dari Tentang → Pembaruan atau Pengaturan → Pembaruan.

Updater membaca endpoint ini:

https://github.com/khalidinsan/badami/releases/latest/download/latest.json

Setiap artefak ditandatangani dengan minisign, dan kunci publiknya tertanam di aplikasi pada src-tauri/tauri.conf.json. Pembaruan yang tidak lolos verifikasi terhadap kunci tersebut akan ditolak.

Menghapus instalasi

Hapus aplikasi seperti biasa di platform Anda. Jika Anda juga ingin menghapus data, hapus folder pendukung aplikasi (~/Library/Application Support/com.khalid.badami/ di macOS). Jika Anda pernah mengaktifkan Local Dev, lihat Local Dev → Menghapus instalasi untuk komponen dengan hak istimewa yang dapat dipasangnya.
