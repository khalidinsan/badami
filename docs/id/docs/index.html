Dokumentasi Badami

Badami menyatukan alat yang biasa Anda pakai untuk merilis perangkat lunak ke dalam satu aplikasi desktop. Semuanya disimpan secara lokal di SQLite, dan sinkronisasi cloud bersifat opsional.

Instalasi

Unduh penginstal siap pakai untuk macOS, Windows, atau Linux, lewati peringatan saat pertama dibuka di macOS, dan biarkan updater dalam aplikasi menangani sisanya.

Proyek dan halaman

Atur pekerjaan ke dalam proyek, tulis di editor blok, dan simpan spesifikasi serta catatan di samping tugas yang bersangkutan.

Tugas

Daftar pintar, label, subtugas, tenggat waktu, pekerjaan berulang, dan pengingat, dalam tampilan daftar atau papan.

Perencanaan dan Hari Ini

Rencanakan hari di kalender, lalu bekerja dari jendela kecil yang mengambang dengan pengatur waktu Pomodoro.

Server

Terminal SSH, pengelola berkas, perintah tersimpan, dan editor jarak jauh, dengan rahasia yang disimpan di keychain sistem.

Brankas kredensial

Satu master password untuk brankas terenkripsi, dengan autentikator TOTP dan pembuat password.

Alat REST API

Susun dan kirim permintaan, atur ke dalam koleksi, dan simpan variabel untuk tiap environment.

Klien database

MySQL, PostgreSQL, dan SQLite dengan penjelajah tabel, editor skema, dan tab kueri.

Asisten AI

Mengobrol dengan model OpenRouter mana pun, dengan balasan streaming dan penggunaan tool, dari jendela yang sama.

Statistik dan pencarian

Dasbor 30 hari terakhir, dan command palette yang menemukan apa pun di dalam aplikasi.

Sinkronisasi

Replikasi opsional ke Turso, agar pekerjaan yang sama ada di lebih dari satu komputer.

Local Dev macOS

Menyajikan *.test situs dari nginx, PHP-FPM, MariaDB, dan Redis yang dipasang dan dikelola sendiri oleh Badami.

Referensi pengaturan

Setiap opsi di aplikasi, beserta nilai bawaannya dan efek perubahannya.

Pintasan papan tik

Setiap pintasan tombol, dikelompokkan menurut tempatnya bekerja.

Di mana data Anda disimpan

Badami menyimpan semuanya lebih dulu di mesin Anda. Dua database berdampingan di dalam akun pengguna Anda:

Berkas Fungsi
badami.db Database lokal. Selalu ada.
badami_sync.db Replika tertanam, dibuat hanya saat sinkronisasi cloud diaktifkan.

Keduanya berada di folder pendukung aplikasi, yang di macOS adalah ~/Library/Application Support/com.khalid.badami/.
