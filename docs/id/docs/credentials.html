Brankas kredensial

Satu master password melindungi setiap login, key, dan catatan yang Anda simpan di Badami, semuanya terenkripsi sebelum menyentuh database.

Master password

Brankas terkunci di balik satu master password. Semua isinya dienkripsi dengan AES-256-GCM, dan key-nya diturunkan dari master password dengan Argon2. Membuka brankas itulah yang membuat entri bisa dibaca; sebelum itu semuanya masih berupa ciphertext.

Brankas terkunci otomatis setelah periode idle yang dapat diatur. Default-nya 15 menit. Ada juga pengaturan petunjuk password untuk berjaga-jaga jika Anda lupa master password.

Satu password mengunci semuanya

Master password adalah satu-satunya kunci brankas. Jika Anda mengatur petunjuk, petunjuk itu hanya membantu mengingatkan Anda; petunjuk tersebut tidak membuka apa pun.

Tipe kredensial

Ada sembilan tipe, masing-masing dengan field rahasianya sendiri:

Tipe Untuk
Login webLogin situs dengan username dan password.
Akun aplikasiAkun aplikasi desktop dan seluler.
API keyToken dan key layanan.
DatabaseKoneksi database.
EmailAkun email.
LisensiKey lisensi perangkat lunak.
Catatan amanTeks bebas yang harus tetap rahasia.
Variabel environmentPasangan key dan value untuk sebuah proyek.
Akses serverKredensial mesin yang dapat ditautkan ke server.

Field umum

Setiap kredensial juga membawa field berikut, di samping rahasia khusus tipenya:

  • Nama.
  • Username.
  • URL.
  • Nama layanan.
  • Environment: Production, Staging, Development, atau None.
  • Tag.

TOTP

Sebuah kredensial dapat menyimpan shared secret untuk kode dua faktor. Badami menghasilkan kode 6 digit saat ini dan menampilkan hitung mundur sampai kode berganti. SHA1, SHA256, dan SHA512 didukung.

Pembuat password

Saat Anda membuat rahasia baru, pembuat password menyusun password yang kuat untuk Anda alih-alih membiarkan Anda mengarangnya sendiri.

Penautan

Kredensial tidak harus berdiri sendiri:

  • Sebuah kredensial dapat ditautkan ke sebuah proyek.
  • Satu Akses server kredensial dapat ditautkan ke server, dan opsi autentikasi From Credential Manager pada formulir server mengarah padanya.
Dua penyimpanan rahasia yang terpisah

Master password brankas terpisah dari keychain sistem operasi Anda. Password server tersimpan di keychain. Rahasia brankas tersimpan di brankas terenkripsi. Membuka salah satunya tidak membuka yang lain.
