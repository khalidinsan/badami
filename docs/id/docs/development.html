Pengembangan

Badami adalah aplikasi Tauri v2: backend Rust, frontend React dan TypeScript, serta SQLite untuk penyimpanan.

Kebutuhan

Alat Versi
Node.js 20 LTS atau lebih baru
Rust stabil, 1.77 atau lebih baru
Tauri CLI v2, dipasang melalui skrip npm proyek

Instalasi Rust

macOS dan Linux:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
rustup update stable

Di Windows, jalankan rustup-init.exe dan pasang juga Microsoft C++ Build Tools dengan workload Desktop development with C++ workload.

Paket platform

macOS:

xcode-select --install

Ubuntu atau Debian:

sudo apt update
sudo apt install -y \
  libwebkit2gtk-4.1-dev libssl-dev \
  libayatana-appindicator3-dev librsvg2-dev \
  patchelf pkg-config

Menjalankan dari sumber

git clone https://github.com/khalidinsan/badami.git
cd badami
npm install
npm run tauri dev

Jalan pertama mengompilasi crate Rust dan memakan beberapa menit. Jalan berikutnya bersifat inkremental. Frontend juga punya server pengembangan khusus peramban di npm run dev, yang berguna untuk pekerjaan tata letak tetapi tidak menyediakan perintah Tauri.

Pengujian

# Rust
cd src-tauri && cargo test --lib

# Frontend
npm test

# Types
npx tsc --noEmit

Beberapa pengujian Rust membaca keadaan mesin yang sebenarnya, misalnya apakah server MariaDB sedang memegang sebuah datadir, dan beberapa perlu instalasi aktif untuk disalin. Pengujian itu ditandai #[ignore] dan dijalankan saat dibutuhkan: 

cd src-tauri && cargo test --lib -- --ignored

Membangun bundel rilis

# Only needed to produce signed updater artifacts
# export TAURI_SIGNING_PRIVATE_KEY="$(cat ~/.tauri/badami.key)"
# export TAURI_SIGNING_PRIVATE_KEY_PASSWORD=""

npm run tauri build

Bundel dihasilkan di src-tauri/target/release/bundle/:

Platform Artefak
macOS .dmg, .app, ditambah .app.tar.gz saat artefak updater diaktifkan
Windows NSIS .exe dan .msi
Linux .deb, .AppImage, .rpm

Menerbitkan rilis

Nomor versi tersimpan di tiga berkas dan harus selalu sinkron. Fase fitur baru menaikkan versi minor, sebuah perbaikan menaikkan versi patch.

Berkas Kolom
package.json "version"
src-tauri/tauri.conf.json "version"
src-tauri/Cargo.toml version

Halaman About membaca versi melalui Tauri, jadi tidak pernah perlu diedit manual. Mendorong tag akan menjalankan alur kerja rilis, yang membangun di macOS, Ubuntu, dan Windows, menerbitkan GitHub Release, serta mengunggah latest.json untuk updater dalam aplikasi: 

git tag v1.16.0
git push origin v1.16.0

Alur kerja ini membutuhkan TAURI_SIGNING_PRIVATE_KEY rahasia, dan opsional TAURI_SIGNING_PRIVATE_KEY_PASSWORD. Tanpa kunci tersebut, artefak updater tidak dapat dihasilkan.

Konvensi

  • TypeScript berjalan dalam mode strict; build gagal jika ada kesalahan tipe.
  • Akses database melalui Kysely, bukan SQL mentah, di luar migration.
  • State berada di store Zustand, satu untuk tiap domain.
  • ID berupa UUID v4 dan timestamp berupa string ISO.
  • Ikon berasal dari Lucide React, tidak pernah emoji.
