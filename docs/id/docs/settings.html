Pengaturan

Setiap opsi di aplikasi, dikelompokkan seperti cara halaman Pengaturan mengelompokkannya, beserta nilai awalnya dan apa yang berubah jika diubah.

Tampilan

Setelan Bawaan Efek
Tema Gelap Terang, Gelap, atau mengikuti sistem. Berlaku seketika, di semua tempat.

Pomodoro Timer

Ini mengatur panjang setiap fase. Nilai yang berlaku saat Anda memulai sesi disimpan bersama sesi itu, jadi mengubah panjangnya nanti tidak menulis ulang riwayat.

Setelan Bawaan Rentang
Durasi kerja 25 menit 1 sampai 120
Durasi istirahat 5 menit 1 sampai 60

Jendela Hari Ini

Setelan Bawaan Efek
Selalu di atas secara default Aktif Dimaksudkan untuk mengatur apakah jendela Hari Ini yang mengambang tetap di atas jendela lain. Lihat catatan di bawah.
Tombol ini saat ini tidak melakukan apa pun

Jendela Hari Ini selalu dibuat di atas terlepas dari pengaturan ini, dan tombol pin-nya sendiri hanya mengubah jendela yang sedang berjalan tanpa menyimpan perubahan. Untuk sekarang, anggap jendela ini selalu di atas.

Sistem

Setelan Bawaan Efek
Jalankan saat login Nonaktif Mendaftarkan Badami sebagai item login agar sudah berjalan saat Anda masuk.
Tutup ke system tray Aktif Menutup jendela membuat Badami tetap berjalan di latar belakang, sehingga pengingat dan sinkronisasi tetap bekerja. Nonaktifkan untuk keluar saat jendela ditutup.
Tampilkan aplikasi di Dock Aktif Apakah Badami muncul di Dock macOS.

Pembaruan

Menampilkan versi saat ini dan memeriksa GitHub Releases untuk build yang ditandatangani. Jika tersedia, unduh dan pasang, lalu aplikasi dimulai ulang. Pembaruan diverifikasi terhadap kunci penandatangan yang tertanam di aplikasi, sehingga build yang tidak cocok ditolak.

Sinkronisasi Lintas Perangkat

Replikasi cloud opsional melalui database Turso. Nonaktif secara default. Lihat Sinkronisasi untuk gambaran lengkapnya, termasuk apa yang direplikasi dan yang tidak.

Setelan Bawaan Efek
Aktifkan sinkronisasi Nonaktif Mengaktifkan replikasi dan membuat replika lokal saat pertama kali dijalankan.
URL database Kosong Endpoint Turso yang menjadi tujuan replikasi.
Interval sinkronisasi 5 menit Seberapa sering aplikasi mendorong dan menarik data di latar belakang.
Sinkronkan saat dijalankan Aktif Menjalankan sinkronisasi saat aplikasi dimulai.
Sinkronkan saat ditutup Aktif Menjalankan sinkronisasi saat aplikasi ditutup, agar perubahan terakhir tidak tertinggal.
Tampilkan status sinkronisasi Aktif Menampilkan indikator sinkronisasi di antarmuka.

Brankas Kredensial

Setelan Bawaan Efek
Batas waktu kunci otomatis 15 menit Mengunci brankas setelah tidak ada aktivitas selama ini, sehingga meninggalkan meja tidak membuatnya tetap terbuka.
Petunjuk kata sandi Kosong Pengingat yang ditampilkan di layar buka kunci. Disimpan sebagai teks biasa, jadi jangan menaruh kata sandinya sendiri di sana.

Kunci PEM

Kelola kunci privat yang dipakai untuk autentikasi SSH: impor kunci, beri nama, dan secara opsional simpan passphrase. Kunci yang diimpor dienkripsi saat disimpan. Kunci yang tersimpan kemudian dapat dipilih sebagai metode autentikasi pada sebuah server.

Local Dev

Pengaturan, Doctor, dan kontrol runtime untuk stack PHP lokal berada di tab Local Dev. Semuanya dibahas lengkap di halaman Local Dev:

Setelan Bawaan Efek
Port HTTP 8080 Port yang diikat nginx. Menyimpan nilai baru akan membuat ulang konfigurasi dan memulai ulang nginx.
Versi PHP default 8.4 Dipakai oleh situs yang tidak dipatok ke versinya sendiri.
TLD test Sufiks domain untuk setiap situs lokal.
Alamat loopback 127.0.0.1 Alamat yang di-resolve oleh situs dan DNS.
Aktifkan Local Dev Aktif Menyembunyikan modul ini dari sidebar dan command palette saat dinonaktifkan. Hanya macOS.

Di mana pengaturan disimpan

Semua yang ada di halaman ini adalah baris di tabel settings di dalam database lokal Anda, kecuali nilai yang menjadi milik sistem operasi: pendaftaran item login, serta kata sandi server dan passphrase PEM, yang berada di keychain. Pengaturan yang mendeskripsikan mesin ini, seperti path dan port Local Dev, dikecualikan dari sinkronisasi cloud agar komputer kedua tidak mewarisi path yang tidak ada di sana.
