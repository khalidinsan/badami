## Source / adaptations (Badami Local Dev)

- Upstream: https://github.com/laravel/valet (MIT)
- Also consulted on-disk Laravel Herd `Resources/valet/` layout for compatibility
  with the `HERD_HOME` / `config/valet` contract used by existing installs.
- Badami patches:
  - Thin `server.php` wrapper defaulting `$_SERVER['HERD_HOME']`
  - `_valet_server.php` body with **`__DIR__`-based** requires (Key Decision 24)
  - `cli/includes/require-drivers.php` uses `__DIR__` (not cwd-relative `./cli/…`)
  - Lightweight `cli/templates/404.php` (no embedded assets)
  - Laravel driver: no Herd inject hooks; no Symfony Process dependency
- **Not included (MVP):** full Valet CLI (`app.php`, Brew, Nginx managers),
  `vendor/` Composer tree, Adminer, dump server phar, njs helpers.

### Included drivers (MVP)

| Driver | Purpose |
| --- | --- |
| `BasicValetDriver` | Plain PHP / static sites |
| `BasicWithPublicValetDriver` | Sites with a `public/` folder |
| `LaravelValetDriver` | Laravel (`public/index.php` + `artisan`) |
| `Specific/*` | WordPress, Symfony, Craft, Drupal, Statamic, Bedrock, etc. |

FPM pools generated by Badami set `chdir = {local-dev}/valet-server` in addition
to the `__DIR__` patches above.
